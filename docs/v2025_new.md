
# FileMaker 2025 New Features

SQL and ODBC/JDBC support exporting value list items through two new system tables: FileMaker_ValueLists returns information about all value lists in the file, and FileMaker_ValueList_XXX returns the items for a specific value list.

SQL supports renaming tables and fields using standard SQL ALTER TABLE syntax with RENAME TO and RENAME COLUMN commands.

To enable ODBC/JDBC client applications to create a table with a container field that uses secure storage and the With fewer folders option in a FileMaker data source, the SQL statement CREATE TABLE supports the FEWER_FOLDERS keyword. For example:

```sql
CREATE TABLE MyDatabase (C1 BLOB EXTERNAL 'Files/MyDatabase/' SECURE FEWER_FOLDERS)
```
